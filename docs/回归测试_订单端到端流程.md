## ETSY 订单系统回归测试检查清单 v2.0

版本: 2.0 | 更新日期: 2026-04-05 | 维护人: 运营团队

### 一、文档用途

本清单用于每次代码修改、功能优化或bug修复后，进行标准化回归测试。

核心覆盖:
- 订单创建 -> 效果图生成 -> 邮件发送 -> 外链交互 -> 状态流转
- 测试频率: 每次上线前必须执行
- 测试耗时: 约 45-60 分钟

### 二、环境准备(5分钟)

 后端服务: poetry run uvicorn src.api.main:app --reload --port 8000
  验证: http://localhost:8000/health 返回 HTTP 200

 前端服务: npm run dev
  验证: http://localhost:5173 能打开登录页

 数据库: Supabase 连接正常

 测试数据: 运行重置 SQL 脚本初始化订单

### 三、核心流程检查

流程一级: 订单创建与确认
 页面打开无报错，新订单Tab显示订单列表
 右侧订单详情显示完整字段(ID、客户、国家、SKU、正背文字、颜色、尺寸)
 设计器iframe成功加载，数据预填充
 点击确认设计稿后，effect_image_url非空

流程二级: 首封邮件发送
 邮件模板和落款选项可用
 邮件预览框显示正确内容(无未替换变量)
 点击传送成功，订单移至待回复，email_logs新增记录

流程三级: 沟通外链(ServiceLink)
 Token验证成功，页面加载，显示店铺名
 左侧订单分组显示，订单卡片完整
 确认设计和需要修改按钮功能正常

流程四级: 修改外链(DesignLink)
 页面加载正常，三卡片显示(订单、效果图、时间)
 设计器加载，数据预填充
 快捷标签、AI生成、邮件发送功能正常

流程五级: 状态流转
 新订单 -> 待回复 -> 待创建 状态正确
 修改分支: 待回复 -> 客户修改 -> 待回复 正确
 Tab间订单字段一致，效果图URL一致

流程六级: UI与交互
 布局: 左右比例68:32，三卡片高度150px
 交互: Tab切换流畅，按钮状态正确

### 四、异常场景

 Token验证失败 -> 显示错误页
 网络中断 -> 显示错误且可重试
 长文本 -> 正确截断不溢出
 特殊字符 -> 正确显示无乱码
 图片失败 -> 显示备用内容

### 五、控制台检查

 Console无Error日志(Warning可以有)
 API返回HTTP200/201，无5xx错误

### 六、快速排查

问题 | 排查步骤
页面无法加载 | 检查npm/poetry运行；检查.env
订单列表为空 | 运行重置SQL；检查Supabase
设计器不显示 | 检查/designer-standalone.html；检查跨域
效果图丢失 | 检查Storage；检查URL有效性
邮件未发送 | 检查后端服务；查看email_logs表
外链无法访问 | 检查token；检查店铺代码
状态未流转 | 查看orders.status；检查后端日志
